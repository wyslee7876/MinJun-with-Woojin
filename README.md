# 🎵 Ticket Helper (티켓헬퍼)

## JSP/Servlet 프로젝트

Java 웹 프로젝트는 Maven WAR로 패키징합니다. 저장소 루트에서 `mvn clean package`를 실행하면 `target/tickethelper.war`가 생성됩니다.

디렉터리 구조와 실행 방법은 [JSP/Servlet 개발 가이드](docs/java-web.md)에서 확인할 수 있습니다.

> **내 주변의 공연을 발견하는 가장 쉬운 방법!**
>
> 공연을 찾는 순간부터 집에 돌아가는 순간까지, 공연 경험의 모든 과정을 연결하는 지도 기반 공연 정보 플랫폼

## 📌 프로젝트 소개

**Ticket Helper**는 전국의 콘서트, 음악 페스티벌, 지역 축제 및 소규모 공연 정보를 한곳에서 확인할 수 있는 웹 플랫폼입니다.

기존 공연 정보는 여러 예매 사이트와 커뮤니티에 분산되어 있어 사용자가 원하는 공연을 찾기 어렵다는 문제가 있습니다.

Ticket Helper는 이러한 불편함을 해결하기 위해 **지도 기반 공연 탐색 기능**을 중심으로 공연 정보, 페스티벌 타임테이블, 날씨, 귀가 교통 정보 등을 통합적으로 제공합니다.

### 🎯 프로젝트 목표

- 🗺️ 지도에서 내 주변의 공연과 페스티벌을 쉽게 발견
- 🔎 지역, 날짜, 장르별 공연 정보 검색
- 🎤 아티스트별 공연 시간 및 무대 순서 확인
- 📅 관심 공연을 저장하고 개인 일정 관리
- 🌦️ 공연 당일 날씨 및 교통 정보 제공
- 🎟️ 공식 예매 사이트 연결 및 티켓팅 편의 기능 제공

## 💡 기획 배경

### 1. 공연 정보를 찾기 어렵다

공연 정보가 여러 플랫폼에 분산되어 있어 사용자가 직접 여러 사이트를 검색해야 합니다.

특히 지역 축제, 인디 공연, 소규모 콘서트는 정보를 발견하기 어렵습니다.

**해결 방안**

지도 기반으로 주변 공연을 시각화하고, 지역별 공연 정보를 한눈에 확인할 수 있도록 합니다.

### 2. 페스티벌 일정 관리가 불편하다

여러 아티스트가 동시에 공연하는 페스티벌에서는 공연 시간과 무대 위치를 일일이 확인해야 합니다.

**해결 방안**

아티스트별 타임테이블을 제공하고 관심 무대를 선택해 개인 일정표를 구성할 수 있도록 합니다.

### 3. 공연 이후 귀가가 어렵다

공연 종료 시간이 늦어지면 대중교통 막차를 놓치는 상황이 발생할 수 있습니다.

**해결 방안**

공연장 주변 교통 정보와 막차 시간을 제공하고 귀가 준비 알림 기능을 구현합니다.

### 4. 티켓팅 준비 과정이 복잡하다

예매 일정, 선예매 조건, 인증 절차 등이 복잡해 예매 기회를 놓치는 경우가 발생합니다.

**해결 방안**

예매 일정 알림, 공식 예매 링크, 티켓팅 준비 체크리스트 등을 제공합니다.

## 🚀 주요 기능

### 🥇 Phase 1. 지도 기반 공연 탐색 (MVP)

프로젝트의 핵심 기능으로, 사용자가 주변 공연을 쉽게 발견할 수 있도록 합니다.

| 기능 | 설명 |
|---|---|
| 전국 공연 지도 | 대한민국 지도에 공연 및 페스티벌 위치 표시 |
| 주변 공연 탐색 | 사용자 위치 또는 선택한 지역 기반 공연 검색 |
| 공연 필터링 | 지역, 날짜, 장르별 공연 검색 |
| 공연 상세 정보 | 공연명, 장소, 날짜, 출연진, 가격 등 표시 |
| 공식 예매 연결 | 공식 티켓 예매 사이트로 이동 |

### 🥈 Phase 2. 페스티벌 올인원

공연 당일의 편의성과 사용자 경험을 개선하기 위한 기능입니다.

| 기능 | 설명 |
|---|---|
| 페스티벌 타임테이블 | 아티스트별 공연 시간 및 무대 순서 확인 |
| 관심 무대 등록 | 보고 싶은 아티스트 및 공연 즐겨찾기 |
| 개인 일정표 | 관심 무대를 기반으로 나만의 일정 구성 |
| 일정 충돌 알림 | 관심 공연의 시간이 겹치는 경우 안내 |
| 날씨 정보 | 공연장 주변 날씨 및 강수 확률 제공 |
| 막차 정보 | 공연장 주변 대중교통 막차 정보 제공 |
| 귀가 알림 | 막차 시간에 맞춘 귀가 준비 알림 |
| 쉬는 시간 추천 | 관심 무대 사이의 휴식 가능 시간 안내 |

### 🥉 Phase 3. 티켓팅 도우미

공연 예매 준비 과정에서 발생하는 불편함을 해결하기 위한 기능입니다.

| 기능 | 설명 |
|---|---|
| 예매 일정 관리 | 선예매 및 일반예매 일정 확인 |
| 예매 오픈 알림 | 티켓 예매 시작 전 알림 |
| 티켓팅 체크리스트 | 로그인, 본인인증, 결제 수단 등 사전 확인 |
| 취소표 정보 | 공식 판매처에서 확인 가능한 취소표 정보 안내 |
| 관심 공연 알림 | 즐겨찾기한 공연의 예매 일정 안내 |

※ 일부 기능은 외부 API 및 데이터 제공 여부에 따라 구현 범위가 변경될 수 있습니다.

## 🛠️ 기술 스택

### Frontend

| 기술 | 용도 |
|---|---|
| HTML5 | 웹페이지 구조 및 콘텐츠 구성 |
| CSS3 | UI 디자인 및 반응형 레이아웃 |
| JavaScript (Vanilla JS) | 사용자 인터랙션, 지도 제어 및 비동기 통신 |

### Backend

| 기술 | 용도 |
|---|---|
| Java | 서버 비즈니스 로직 |
| Java Servlet | HTTP 요청 처리 및 REST API 구현 |

### 추가 기술 (검토 예정)

- **Apache Tomcat** — Servlet 기반 웹 애플리케이션 실행
- **MySQL 또는 MariaDB** — 공연, 사용자 및 즐겨찾기 데이터 저장
- **Kakao Maps 또는 Naver Maps API** — 지도 및 공연 위치 표시
- **공공데이터 API** — 공연 및 행사 정보 수집
- **날씨 API** — 공연장 주변 날씨 정보 조회
- **대중교통 API** — 막차 및 교통 정보 조회

- 관심 아티스트 즐겨찾기

- 공연 일정 충돌 표시

- 즐겨찾기한 아티스트

## 🎯 기대 효과

**사용자 측면**

- 주변 공연을 더욱 쉽고 빠르게 발견
- 여러 사이트를 방문하지 않고 공연 정보 확인

- 공연 탐색부터 관람까지 연결되는 통합 서비스 구축
